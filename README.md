# Onely Creator Growth OS

## AI 驱动的海外创作者招募、筛选与激活系统

> 一个面向 Onely 创作者生态的 AI
> 增长基础设施原型，帮助团队在短时间内发现、评估、触达并激活具备美国社媒运营能力的创作者运营人员。

------------------------------------------------------------------------

# 一、项目背景

## 为什么需要这个系统？

Onely 的业务模式依赖海外创作者生态：

-   创作者创建 AI 角色
-   通过 TikTok、X、Discord 等海外渠道获取用户
-   与用户建立情感连接
-   通过订阅、付费互动等方式实现商业转化

但在创作者招募过程中，传统方式存在明显效率问题：

  问题         传统方式       痛点
  ------------ -------------- --------------
  创作者发现   人工搜索       覆盖范围有限
  人选判断     人工经验筛选   难以规模化
  招募触达     统一模板私信   回复率低
  后续运营     分散管理       激活效率低

因此，本项目希望构建：

> 一个 AI 辅助的 Creator Growth
> OS，将创作者发现、筛选、触达、管理和激活流程标准化。

# 三、核心功能

## 1. 创作者线索管理

### 解决问题

海外创作者信息通常分散：

-   TikTok 主页
-   X 账号
-   Discord ID
-   邮箱
-   推荐来源

人工整理容易出现：

-   重复联系
-   信息遗漏
-   无法追踪来源

### 已实现能力

✅ CSV / JSON 导入

✅ 字段标准化

✅ 多来源去重

✅ 创作者档案管理

✅ 来源渠道追踪

示例：

输入：

``` json
{
"name": "Alex",
"platform": "TikTok",
"followers": 52000,
"location": "US",
"category": "AI Content Creator"
}
```

输出：

    创作者评分：86

    等级：
    A 类优先触达

    原因：
    ✓ 美国用户覆盖
    ✓ AI 内容经验
    ✓ 较高互动能力

# 四、AI 创作者筛选模型

## 核心思想

不只看粉丝量，而是判断：

> 这个人是否具备运营 AI 角色并获取美国用户流量的能力。

评分模型：

    Creator Score =

    35% 美国市场经验

    +

    25% 社媒增长能力

    +

    20% 内容生产能力

    +

    20% 商业化经验

分层：

  分数     等级   动作
  -------- ------ ----------
  80-100   A      优先招募
  60-80    B      持续培养
  \<60     C      暂不推进

# 五、AI 个性化触达助手

## 问题

普通招募消息：

    Hi，加入我们的平台吧！

缺少针对性。

------------------------------------------------------------------------

## 解决方案

根据创作者画像自动生成触达内容。

示例：

    Hi Sarah，

    我关注到你的 TikTok 主要围绕 AI 角色创作和故事内容。

    我们正在搭建一个 AI 创作者生态，
    帮助创作者创建 AI 人格并通过用户关系实现商业化。

    希望邀请你参与我们的 Beta 计划。

能力：

-   根据创作者背景生成文案
-   支持人工审核
-   记录触达状态
-   管理后续跟进

# 十三、设计理念

## 1. AI 降低重复劳动，而不是替代人工判断

AI 负责：

-   信息整理
-   初步筛选
-   文案生成
-   数据分析

人工负责：

-   高价值候选判断
-   商务沟通
-   合规审核

## 2. 增长系统需要形成闭环

    发现

    ↓

    招募

    ↓

    激活

    ↓

    运营

    ↓

    数据反馈

    ↓

    优化

## 3. 复用已有能力，而不是重复造轮子

项目参考成熟 CRM、自动化工作流和 AI Recruiting Pipeline 的设计方式。

同时针对 Onely 业务特点，设计：

-   Creator Score
-   招募漏斗
-   AI Outreach
-   社群激活流程
